---
name: sequential_rule_manipulation
description: Break down rules into steps to strategically move towards desired conditions.
---

When faced with a complex configuration of rules and blocks, it is beneficial to adopt a sequential approach to manipulation. This means evaluating the current state, determining what needs to be changed first, and proceeding stepwise. For example, if the goal is to reach a win condition while blocked, the first step might involve moving a key rule next to a door before attempting to access the win condition. Working in increments allows for greater control and understanding of how changes affect each other.
