---
name: explore_adjacent_blocks
description: Assess nearby blocks for useful rule manipulations or paths to win.
---

This skill encourages the agent to closely inspect adjacent rules and objects. By understanding how surrounding blocks interact, the agent can determine if there’s a way to change the dynamic of the board or bypass obstacles. For instance, if a nearby block can be moved to redefine a win condition or create a clear path, this skill facilitates identifying and taking advantage of those opportunities. The focus here is on thorough exploration and critical assessment.
