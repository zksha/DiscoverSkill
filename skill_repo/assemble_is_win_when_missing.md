---
name: assemble_is_win_when_missing
description: When no WIN rule exists, form '<NOUN> IS WIN' using available text safely.
---

If Active rules contain no "IS WIN", treat the level as make_win. Identify movable text for a candidate Noun (prefer a noun with an available f-object on the map, e.g., FLAG/KEY/BALL/DOOR rather than BABA), an IS, and a WIN. Your goal is to align them horizontally or vertically as "NOUN IS WIN".

Plan assembly with minimal pushes: first bring IS and WIN adjacent and aligned, then attach the NOUN. Approach text from behind so a single push slides it into position. While moving text, protect "BABA IS YOU": do not push its IS or YOU out of alignment. If "BABA IS YOU" uses the only IS, duplicate or reposition another IS if possible before disturbing it.

After forming "NOUN IS WIN", navigate to the corresponding f-object to win. If you instead form "BABA IS WIN" while "BABA IS YOU" remains active, the win usually triggers immediately; only do this if it’s faster and safe. If STOP rules block access to the necessary text, consider first breaking or bypassing STOP (e.g., nudging the STOP text out of its rule) before continuing assembly.

As you push, re-check Active rules each step to ensure you didn’t accidentally create a losing state (no YOU). If that happens, undo or restore "YOU" before proceeding.
